# Notes REST API

API REST desarrollada con Node.js, Express y MySQL.

## Características

- Registro e inicio de sesión de usuarios.
- Autenticación mediante JWT.
- Operaciones CRUD de notas.
- Autorización por propietario.
- Validación de datos.
- Pruebas automatizadas con Jest y Supertest.

## Tecnologías

- Node.js
- Express
- MySQL
- JWT
- bcryptjs
- Jest
- Supertest

## Instalación

1. Clonar el repositorio.
2. Instalar dependencias con `npm install`.
3. Crear `.env` a partir de `.env.example`.
4. Configurar MySQL y crear las tablas necesarias.
5. Ejecutar `npm run dev`.
